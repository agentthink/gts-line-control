## 6. RS232/485 串口驱动测试

### 6.1 测试环境

- 虚拟串口对：COM7 ↔ COM8（com0com）
- 测试工具：UartAssist V5.0.14
- 驱动配置：9600-8-N-1

### 6.2 原始流模式

| 测试项 | 结果 |
|--------|------|
| 打开 COM7 | 通过 |
| 打开 COM8 | 通过 |
| COM7 → COM8 发 `Hello\r\n` | 收到 |
| COM8 → COM7 发 `ddd` | 收到 |
| 发送 HEX 数据 `48 65 6C 6C 6F` | 收到 `Hello` |
| 接收区实时显示 | 通过 |
| 自动滚动 | 通过 |

### 6.3 分隔符帧模式

**配置**：分隔符 = `0D 0A`（`\r\n`）

| 发送内容（HEX） | 是否收到 | 说明 |
|-----------------|----------|------|
| `48 65 6C 6C 6F 0D 0A` | 收到 | 以 `\r\n` 结尾，被解析为一帧 |
| `64 64 64 0D 0A` | 收到 | `ddd\r\n` |
| `48 65 6C 6C 6F` | 未收到 | 无分隔符，等待更多数据 |
| `41 0D 0A 42 0D 0A` | 收到两帧 | 两次触发，两帧 |

### 6.4 定长帧模式

**配置**：帧长 = 8 字节

| 发送内容 | 收到情况 |
|----------|----------|
| 8 字节 | 1 帧 |
| 16 字节 | 2 帧 |
| 20 字节 | 2 帧 + 4 字节缓存 |

### 6.5 头+长度帧模式

**配置**：帧头 = `AA 55`，长度字段偏移 2，长度 2 字节，含 CRC16

| 报文 | 结果 |
|------|------|
| `AA 55 00 08 01 02 03 04 XX XX` | 收到完整帧 |
| `AA 55 00 08 01 02` | 等待剩余 |
| `00 11 AA 55 00 08 ...` | 丢弃前缀，正确识别 |

### 6.6 自动重连

| 测试步骤 | 结果 |
|----------|------|
| 拔出虚拟串口 | 检测到断开，日志记录 |

## 10. 视觉服务集成测试（HalconVisionServer）

### 10.1 测试环境

- 视觉服务器：HalconVisionServer (端口 503)
- 测量对象：20mm 金属圆片
- 相机：USB 工业相机（640×480 @ 25fps）

### 10.2 算法演进

| 版本 | 优化措施 | 极差 | 标准差 |
|------|----------|------|--------|
| **V1** | Canny + 圆拟合 | 42.7 μm | 9.1 μm |
| **V2** | 增加圆度筛选（≥0.65）+ 半径约束（83~98px） | 30.4 μm | 7.9 μm |
| **V3** | 增加拟合残差双重校验（平均 ≤1.2px，标准差 ≤0.8px）+ 5 帧改 7 帧中位数 | **15.6 μm** | **3.8 μm** |

### 10.3 三级过滤策略

1. **L1 圆度筛选**：circularity ≥ 0.65
2. **L2 半径约束**：83px ≤ radius ≤ 98px
3. **L3 拟合残差校验**：
   - 平均残差 ≤ 1.2px
   - 残差标准差 ≤ 0.8px

### 10.4 关键修复

| 问题 | 原因 | 修复 |
|------|------|------|
| HALCON 随机崩溃 | `GenImageInterleaved` 悬空指针（缺 CopyData） | 生成后立即 `CopyImage` 深拷贝 |
| 内存泄漏 | 跨线程传递 HObject 引用 | 事件触发前 `CopyImage`，原图 `finally` 释放 |
| 边缘跳层 | 高光弧被误判为真实圆 | 三级过滤（圆度 + 半径 + 残差） |

### 10.5 内存稳定性

| 测试项 | 结果 |
|--------|------|
| 1000 次图像迭代 | 内存增长 < 3 MB |
| 4 线程并发 1000 次 | 无崩溃，内存增长 < 5 MB |
| 8 小时连续运行 | 无内存泄漏 |

### 10.6 Modbus 数据一致性

| 项目 | 视觉服务端 | GTS 客户端 | 一致性 |
|------|------------|------------|--------|
| 直径 | 20.15 mm | 20.15 mm | 一致 |
| X 坐标 | -27.34 mm | -27.34 mm | 一致 |
| Y 坐标 | -15.76 mm | -15.76 mm | 一致 |
| 缺陷数 | 0 | 0 | 一致 |

**关键修复**：

1. 服务端写入用 `Math.Round` 而非截断
2. 客户端读取时**移除多余的字节交换**
3. 坐标用 `(ushort)(short)value` 存储，读取 `(short)raw / 100.0`
